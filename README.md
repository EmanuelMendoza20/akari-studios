## Personalización

- **Textos** (título, subtítulo, botones): editar `index.html` y `links/index.html`.
- **Enlaces y redes**: editar los `<a href>` de cada página.
- **Colores**: variables en `:root` al inicio de `styles.css`.
- **Fondos**: reemplazar los archivos WebP en `assets/` (los PNG originales quedan en el historial de git).
- **Desplegar cambios**: hacer commit en `main` y push — GitHub Pages actualiza solo.
